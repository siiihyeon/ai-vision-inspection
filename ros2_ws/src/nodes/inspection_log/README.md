# inspection_log

`LogNode` 패키지이며 Log 담당자 작업 영역입니다.

## 소유 책임

- 제품·촬영·추론·시스템·오류 기록
- SQLite 원본
- 이미지 상대 경로와 제품 로그 연결
- 저장소 health와 spool 상태
- 과거 로그 조회

## 소유하지 않는 것

- 시스템 운전 상태 결정
- 제품 FIFO와 최종 판정 변경
- 장비·카메라 제어
- 운전 명령 중계

## 현재 단계

`log_node` 실행 진입점, Heartbeat, 상태조회 Service, 초기화 Action 골격이 있습니다. 파일이나 데이터베이스를 생성하지 않습니다.
